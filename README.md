# مناوب

صفحة ثابتة تعمل على GitHub Pages، مع عرض عام للبيانات وتعديل للمحررين المعتمدين في Supabase.

## ملفات المشروع

- `index.html`: هيكل الصفحة وترتيب تحميل الملفات.
- `app.css`: تصميم الواجهة والتقويم والرصيد.
- `app-core.js`: بيانات الموظفين المحلية، عرض القائمة، وحساب دورة الشفتات.
- `employee-features.js`: استحقاق الإجازة، الرصيد المتوقع، والتقويم والعطلات الرسمية.
- `cloud-config.js`: عنوان Supabase ومفتاح النشر العام. لا تضع فيه مفتاحاً سرياً أو `service_role`.
- `cloud-sync.js`: تسجيل الدخول، صلاحيات المحررين، قراءة البيانات ومزامنتها مع Supabase.
- `supabase/schema.sql`: بنية الجداول وسياسات القراءة والكتابة.

## ترتيب تحميل JavaScript

يجب أن يأتي `app-core.js` أولاً، ثم `employee-features.js`، وبعدهما إعداد Supabase ومكتبة Supabase، وأخيراً `cloud-sync.js`.

## أين أعدل؟

- ألوان الصفحة وأحجامها: `app.css`.
- معلومات الموظف ودورة 14/14 وعرض الشفتات: `app-core.js`.
- حساب الإجازة والعطلات والتقويم: `employee-features.js`.
- تسجيل الدخول وربط قاعدة البيانات: `cloud-sync.js`.

بعد تغيير ملف JavaScript أو CSS، حدّث قيمة `v=` في رابطه داخل `index.html` حتى يحصل المتصفح على النسخة الجديدة.
